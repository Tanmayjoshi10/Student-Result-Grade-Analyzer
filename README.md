# Student Result and Grade Analyzer

## About the Project
A C programming project developed for a hackathon to automate student result processing and class performance analysis.

## Features
- Accepts marks for five subjects.
- Supports multiple students.
- Calculates total marks and percentage.
- Automatically assigns grades.
- Checks subject-wise pass/fail status.
- Identifies the class topper.
- Calculates class average.
- Displays a complete student-wise result report.

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- Loops and Conditional Statements
- String Handling

## Passing Criteria
A student must score at least 33 marks in every subject to pass.

## Grade System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89% | A |
| 70–79% | B |
| 60–69% | C |
| 50–59% | D |
| 33–49% | E |
| Below 33% | F |

## How to Run

Compile:
```bash
gcc student_result_analyzer.c -o result
```

Run:
```bash
./result
```
